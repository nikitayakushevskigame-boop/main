# Контрольні запитання

1. Тип шрифту змінює font-family. Наприклад, font-family: Arial, sans-serif.
2. Розмір шрифту задає font-size. Наприклад, font-size: 20px.
3. font-weight задає товщину шрифту. Значення bold робить текст жирним.
4. Для курсиву потрібно написати font-style: italic.
5. У font можна записати кілька властивостей разом. Наприклад, font: italic bold 20px Arial, sans-serif.
6. Відстань між буквами задає letter-spacing.
7. text-align вирівнює текст горизонтально, а vertical-align допомагає вирівняти рядкові елементи або вміст комірки таблиці по вертикалі.
8. text-decoration: underline підкреслює текст, а text-decoration: line-through перекреслює.
9. text-transform змінює регістр букв. Основні значення — uppercase, lowercase, capitalize, none.
10. Міжрядковий інтервал задає line-height. Наприклад, line-height: 40px.
11. text-shadow додає тінь до тексту. Наприклад, text-shadow: 3px 3px 5px gray. Тут записані зміщення по горизонталі, зміщення по вертикалі, розмиття і колір.
12. Щоб вибрати абзац із класом red, можна написати p.red.
13. Клас можна використовувати для кількох елементів. ID має бути унікальним на сторінці. Селектор ID має більший пріоритет.
14. Потрібно написати .content p.
15. За однакових інших умов пріоритет зростає так — тег, клас, ID, стиль в атрибуті style.

## Висновок

Я навчився змінювати шрифт, колір і вирівнювання тексту за допомогою CSS. Також використав класи, ID та різні селектори для оформлення елементів.

У кожній папці є HTML-файл і свій style.css. Для перегляду потрібно відкрити HTML-файл у браузері.
